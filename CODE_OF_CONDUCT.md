# Code of Conduct

This repository, like every Falconer repository, adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies in full.

## In short

- Be respectful and welcoming, whatever someone's background, identity or experience.
- Give and accept constructive feedback; focus on what is best for the project and its users.
- No harassment, insults, sexualized language or imagery, personal attacks, or publishing
  someone else's private information.

## Enforcement

The maintainers enforce this code in issues, pull requests, discussions and any other project
space. Report unacceptable behavior through GitHub:

- use **Report content** on the comment, issue or pull request, or
- open a private report from this repository's **Security → Report a vulnerability** form
  (<https://github.com/lesquel/falconer-app/security/advisories/new>) and say it is a conduct
  report.

Reports are handled privately. Maintainers may edit or remove contributions, and warn,
temporarily ban or permanently ban contributors, following the Contributor Covenant's
enforcement guidelines.
